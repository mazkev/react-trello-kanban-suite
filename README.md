# 💎 Glass Elite Trello

A premium, high-fidelity Kanban project management suite built with **React**, **Vite**, **Tailwind CSS**, and **Zustand**. Featuring a stunning "Glassmorphism" aesthetic, real-time state persistence, and advanced productivity tools.

![Landing Page Preview](https://images.unsplash.com/photo-1558655146-d09347e92766?w=1200&q=80)

## ✨ Features

### 🎨 Elite Design System
- **Glassmorphism UI**: Translucent panels with backdrop-blur effects for a premium modern feel.
- **Dynamic Themes**: Toggle between Dark, Black, and Light skins.
- **Scenic Backgrounds**: Choose from curated high-resolution nature backgrounds.
- **Responsive Layout**: Fully functional on desktop and mobile with a collapsible sidebar and bottom navigation.

### 📋 Advanced Kanban Engine
- **Multi-Board Architecture**: Create, rename, and manage multiple independent projects.
- **Drag & Drop**: Intuitive card and list reordering powered by `@hello-pangea/dnd`.
- **Rich Card Modals**: 
  - **Dynamic Labels**: Categorize tasks with vibrant colors.
  - **Interactive Checklists**: Multi-item checklists with live progress bars.
  - **Due Dates**: Integrated calendar picker and deadline tracking.
  - **Visual Covers**: Attach image URLs to cards for better visual organization.

### 🚀 Productivity Tools
- **Global Search**: Instant real-time filtering across all boards and cards.
- **Automation Workflows**: Set up triggers (e.g., "Auto-complete task when moved to Done").
- **Calendar View**: A dedicated chronological view for tracking all upcoming deadlines.
- **Dashboard Statistics**: Real-time analytics of your task distribution.

### 🔐 Authentication & Persistence
- **Landing & Login Flow**: Professional entry sequence with personalized profile generation.
- **Local Persistence**: State is automatically saved to `localStorage` so you never lose your progress.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 5](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **State Management**: [Zustand 5](https://github.com/pmndrs/zustand)
- **Drag & Drop**: [@hello-pangea/dnd](https://github.com/hello-pangea/dnd)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/mazkev/trello.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run in development mode**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
